# 只言 0.6 · 记忆花园

本轮在第一阶段产品优化的基础上，采用用户确认的新方向：**俏皮、可爱，让记忆也可以长出花。** 本文的视觉规则替代旧方案中的冷石板与单一青蓝限制。

## 体验与视觉

- 白日：奶油纸面、叶绿按钮、花粉黄与少量粉色、淡紫花瓣。夜间：深绿底与柔和浅绿，保留花园的温度。
- 保留猫头鹰品牌标识。装饰使用本地 SVG，不加载外部图片或字体。
- 花朵集中在首页、记忆卡片、空状态、保存反馈。没有连续打卡惩罚、枯萎机制或强制养成任务。
- 导航与操作仍叫“记一笔 / 记忆 / 搜索 / 设置”“保存 / 编辑 / 删除”，不以隐喻替代功能含义。
- 只有真实保存成功才显示开花反馈。花朵不代表 AI 已整理、音频已转写或记录已同步。
- 正文使用常规字重；标题有轻微手账感。触控区域、键盘焦点和减少动态效果设置均保留。

## 本轮落地

首页：记录区 + 最近记忆，保存后留在输入页继续记录。文字草稿随导航、主题切换与应用重启保留。

浏览：Mac 列表与详情并排，iPhone 独立详情；时间线按游标分批加载。搜索直接显示原生返回的记录，不再依赖首页已加载的数据；结果刷新不销毁搜索输入框。

详情：编辑正文与标签、真实音频播放 / 暂停 / 拖动、单条导出、软删除与 12 秒撤销入口。

真实状态：设置页明确显示 AI 和同步尚未接入。移除演示额度、虚假连接成功、虚假的已同步设备与问答建议。

可靠性：数据库写失败返回错误，文字草稿不会被清空；停止录音后若保存失败，音频草稿可在重启后重试。短词使用连续词组并校验同一字段内的完整命中；例如搜索“上海”不会命中“海上”。多词先求交集再限制结果数量。

## 代码边界

| 文件 | 职责 |
|---|---|
| `prototype/tokens.css` | 两套主题的颜色、字体、间距与布局变量 |
| `prototype/garden.css` | 花园界面布局与组件样式 |
| `prototype/garden.js` | 确定性的 SVG 花朵与花盆 |
| `prototype/icons.js` | 通用图标与原有猫头鹰标识 |
| `prototype/views.js` | 根据状态生成页面，无原生调用 |
| `prototype/app.js` | 界面状态、输入、导航、异步动作 |
| `prototype/db.js` | 原生数据接口和明确的浏览器预览实现 |
| `build/shell.swift` | 平台窗口、WebView 引导、截图入口 |
| `build/NativeBridge.swift` | 请求分发、数据库串行队列、错误返回、设置落盘 |
| `build/Audio.swift` | 原生录音与播放器 |
| `build/Data.swift` | SQLite、检索、分页、修改、撤销、导出 |
| `build/Diagnostics.swift` | 显式命令行触发的集成自检 |

原生草稿与主题保存在数据库旁的 `preferences.json`；界面预览使用独立 localStorage。浏览器预览有示例数据，真实 App 默认空库。

`--database /绝对路径/notes.db` 可指定隔离数据库。测试音频和导出跟随该数据库目录，避免污染个人记录。

## 验证

```bash
./build/build.sh test      # 数据层回归
node prototype/garden-test.js  # 独立 Chrome profile 中的真实页面交互与截图
./build/build.sh all       # Mac、iOS 模拟器与 DMG
```

原生自检请使用隔离目录；`selftest` 会清空它所连接的数据库：

```bash
mkdir -p verify/local-test
./dist/只言.app/Contents/MacOS/只言 \
  --database "$PWD/verify/local-test/notes.db" --act selftest
```

`garden-test` 还要求隔离数据库旁存在 `media/test-tone.wav`，用测试音频验证原生播放，不需要录制真实环境声音。`draft-check` 在其后重启执行，检查草稿持久化。

本轮已通过 61 项数据层断言、19 项浏览器交互检查；Mac 与 iOS 模拟器各通过 11 项原生检索、9 项编辑/播放、1 项草稿重启检查。iOS 另外通过系统分享面板导出检查。录音采集沿用 v0.5 实现，本轮使用合成音频验证播放，没有采集真实环境声音。
